# Execution outcomes and verifier boundaries

Failures and asyncio cancellation produce termination records before the original exception is propagated. Input hashes refer to a snapshot taken before node mutation. Successful tools without a verifier are explicitly unchecked and do not fabricate V events. Verifiers must return bool; async verifiers are awaited for async nodes, and verifier errors are recorded as failed checks.

Event assignment is serialized for concurrent threads. This package retains its local archive envelope and hash format; J/D/T/V labels here do not claim detached-JWS JEP-Core wire conformance. Use separate tracer instances for separate runs. Regression tests include cancellation, mutable inputs, false-like verifier results, and concurrent chain integrity.
